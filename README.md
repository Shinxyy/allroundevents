# Allround Events — Woonwaard Eindejaarsfeest

Een responsive eventwebsite in gewone HTML, CSS en JavaScript voor het Woonwaard Eindejaarsfeest op 17 december 2026.

## Lokaal bekijken

Open `index.html` direct in de browser of start een eenvoudige webserver:

```bash
python3 -m http.server 4173
```

Open daarna `http://localhost:4173`.

## Mijn events-demo

Klik op **Mijn events** en log in met een geldig e-mailadres en een willekeurig wachtwoord van minimaal vier tekens. De demo bewaart de login- en registratiestatus alleen lokaal in de browser via `localStorage`.

Voor productie moeten de login en registratie worden gekoppeld aan de account- en eventbackend van Woonwaard.
